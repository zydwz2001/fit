# 云同步与账号体系决策清单

当前版本是可独立使用的本地优先 MVP。接入云端前需要先确定以下产品边界，避免后续因数据模型或隐私策略变化而返工。

## 开工前必须确认

1. 登录方式：邮箱验证码、第三方登录，还是两者都要。
2. 同步范围：训练、身体指标、笔记、动作库、模板和照片是否全部同步。
3. 离线策略：默认保留本地优先；同一条记录在多设备修改时采用“最后修改覆盖”还是保留冲突副本。
4. 隐私等级：身体数据是否需要客户端加密，以及找回密码后能否恢复加密数据。
5. 数据生命周期：注销账号时如何导出、删除和确认照片等对象已清理。

## 推荐实施顺序

1. 给现有记录补齐稳定的用户 ID、更新时间和删除标记，建立版本化迁移。
2. 抽象本地存储层，保持当前无网络时仍可正常新增、编辑和删除。
3. 接入账号与云端数据库，先同步结构化文本数据。
4. 增加变更队列、重试、冲突提示和首次登录时的本地数据迁移。
5. 最后接入照片对象存储、访问控制和清理流程。
6. 用双浏览器 / 双设备场景验证新增、并发修改、删除、退出登录和账号注销。

## 验收标准

- 离线记录不会丢失，恢复网络后可自动重试。
- 新设备登录后能恢复全部已同步数据。
- 同一记录并发修改不会静默覆盖且无提示。
- 用户能导出自己的完整数据，并能执行可验证的账号删除。
- 身体照片不可通过未授权公开链接访问。

## 当前阻塞项

需要项目所有者确认登录方式、云服务与隐私等级。它们会决定数据结构、成本和安全实现，不应在只有前端仓库的情况下代替产品方做决定。
